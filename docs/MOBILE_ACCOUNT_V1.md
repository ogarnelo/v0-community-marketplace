# Mobile account v1

## Goal

Make `/account` feel closer to a mobile app profile while keeping Wetudy in the current MVP model: no checkout, no wallet, no orders and no integrated shipping.

## Changes

- Prominent profile header with avatar, name, role and verified/contact badges.
- Quick actions visible on mobile and desktop:
  - Publicar
  - Mis anuncios
  - Mensajes
  - Favoritos
  - Mis acuerdos
  - Soporte
- Keeps agreement wording instead of purchase/order language.
- Keeps profile editing below the summary so the page can work as both a profile hub and settings page.

## Out of scope

- No `Mis compras` wording.
- No wallet.
- No checkout.
- No shipment tracking.
- No native app.
