# Search alerts UI next step

This branch makes the saved-search backend visible in the marketplace empty state.

## User behavior

When a user searches or filters and gets zero results, Wetudy shows:

- `Avísame si aparece`
- `Limpiar filtros`
- `Publicar anuncio`

Authenticated users can save the demand signal. Anonymous users see a sign-in prompt.

## Still not included

- Email delivery for matching saved searches.
- Push notifications.
- Scheduled matching job.
- Public payment, shipping or checkout features.
