# WETUDY — Tres AMPA: protocolo de aceptación de campo
15/11/2026, #245, 0/3 aceptaciones reales.

Para cada una de las tres AMPA obtener en repositorio privado de evidencias: autorización inequívoca del responsable, alcance y fecha de piloto, consentimiento procedente, cuenta de prueba autorizada y resultado E2E con dos familias ficticias. Probar creación y edición de anuncio, código postal/filtrado radio, aislamiento entre A/B, chat, notificaciones, moderación, visualización móvil y limpieza de datos. Evitar identidades de menores, correos privados o pruebas de otras familias.

La referencia opaca private: del manifiesto no acredita el contenido; el gate existente produce go:false y exit 3 aunque todos los booleanos sean true. Un responsable debe revisar evidencias y autorizar explícitamente el entorno de piloto. Mientras tanto no habilitar familias ni activar captación AMPA. Fecha objetivo 26/11 condicionada a #447 y #455.
