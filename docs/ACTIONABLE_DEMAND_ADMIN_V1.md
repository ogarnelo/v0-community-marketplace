# Actionable demand admin

This PR turns demand signals into admin decisions.

## Insight types

- Top text searches without results.
- Top ISBN searches.
- Top categories with demand.
- Top courses with demand.

## Action labels

- `Crear campaña`
- `Pedir este ISBN`
- `Reforzar categoría`
- `Reforzar curso`

## Product intent

The panel should help decide what to ask families, schools and communities to publish next.

## Scope

- No automatic campaigns.
- No bulk email sending.
- No checkout.
- No shipping.
- No payment flow.
