# Saved search UI V1

Adds the visible first step for demand alerts:

- Empty marketplace searches can be saved by authenticated users.
- The CTA appears only when there is a real search/filter intent.
- Saved searches store query, ISBN, category, course, listing type, condition, community scope and result count.
- No emails or push notifications are sent yet.
- The feature keeps MVP scope: Wetudy records demand and can notify later once transactional messaging is connected.
