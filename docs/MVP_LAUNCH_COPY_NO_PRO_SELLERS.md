# MVP launch copy and seller scope

Este cambio ajusta Wetudy al alcance de lanzamiento:

- Wetudy se comunica como punto de encuentro para familias y estudiantes.
- Comunidad/colegio funciona como filtro de confianza, no como bloqueo total.
- Se eliminan métricas infladas o no validadas de la landing.
- Se refuerza que pago y entrega se acuerdan fuera de Wetudy.
- Las cuentas de vendedor profesional no se ofrecen en el registro.
- Si ya existe una cuenta `business`, no puede publicar anuncios durante el MVP.

No toca Supabase y no activa pagos, envíos ni checkout.
