# Cuenta admin MVP

Para el MVP conviene separar claramente:

- Cuenta de administración: usada solo para gestión, pruebas de superadmin o paneles internos.
- Cuentas de prueba de usuario: usadas para publicar, contactar y validar el flujo real de familias.

Estado recomendado:

- No usar la cuenta admin para pruebas normales de compraventa/donación.
- Crear al menos dos cuentas de test normales: una vendedora y una compradora.
- Mantener vendedores profesionales desactivados hasta validar el flujo familiar.

Este documento no cambia permisos en Supabase. Cualquier asignación de rol debe hacerse explícitamente en base de datos.
