# Revisión UX de lanzamiento — 2026-09-13

Notas detectadas durante la prueba manual del flujo real:

## Publicación de anuncios

- La foto obligatoria ya funciona y se persiste en `listings.photos` y `listing_photos`.
- Evitar controles nativos de incremento/decremento en los campos de precio, porque con el ratón pueden modificar decimales accidentalmente.
- `ISBN` debe aparecer solo cuando la categoría seleccionada sea de libros.

## Header / navegación

- La web se percibe lenta en general.
- En el header hay que pinchar varias veces en algunas opciones.
- Al navegar entre opciones, `Marketplace` y `Publicar` pueden quedar resaltadas a la vez porque `/marketplace` se marca activo para cualquier ruta que empiece por `/marketplace`, incluida `/marketplace/new`.

## Detalle de anuncio

- El estado técnico `very_good` debe mostrarse como texto humano en español: `Muy bueno`.
- Evitar expresiones como `fuera de Wetudy`; mejor: `La entrega y el pago se acuerdan directamente entre las partes`.

1. Corregir `isActive()` del header.
2. Ocultar spinners nativos de inputs numéricos o cambiar precio a input textual con validación decimal.
3. Condicionar ISBN a categorías de libros.
4. Formatear etiquetas técnicas de estado.

6. Revisar rendimiento percibido y logs de rutas lentas.
