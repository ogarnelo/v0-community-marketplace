# Supabase Auth email templates for Wetudy

Wetudy uses Supabase SSR/PKCE. Auth links must use `TokenHash` and
`/auth/confirm`, not a browser-local PKCE verifier.

All active Auth emails should use the same Wetudy identity:

- primary blue: `#2563EB`
- accent green: `#7EBA28`
- pale blue background: `#EFF6FF`
- logo: `{{ .SiteURL }}/icon.svg`
- visible text wordmark "Wetudy" next to the image as an email-client fallback

The school-admin invite generated by the application no longer uses the
Supabase **Invite user** email. It is generated with `auth.admin.generateLink`
and delivered through the branded Wetudy/Resend template.

## Reset password

Subject:

`Restablece tu contraseña de Wetudy`

HTML: use the same shell above and replace the content block with:

```html
<h2 style="margin:0 0 14px;">Restablece tu contraseña de Wetudy</h2>
<p>Usa este enlace para elegir una nueva contraseña.</p>
<p style="margin:20px 0;">
  <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=recovery&next=/auth/update-password"
     style="display:inline-block;padding:13px 18px;background:#2563EB;border-radius:12px;color:#fff;text-decoration:none;font-weight:700;">
    Crear nueva contraseña
  </a>
</p>
<p style="font-size:13px;color:#6B7280;">Si no solicitaste este cambio, puedes ignorar este mensaje.</p>
```

## Invite user fallback

The application-managed school invitation bypasses this template. Keep the
Supabase fallback branded anyway for any future Dashboard-created invite.

Subject:

`Activa tu acceso a Wetudy`

Use the same shell and this content:

```html
<h2 style="margin:0 0 14px;">Activa tu acceso a Wetudy</h2>
<p>Has recibido una invitación para acceder a Wetudy.</p>
<p style="margin:20px 0;">
  <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=invite&next=/auth/complete-invite?next=/admin/school"
     style="display:inline-block;padding:13px 18px;background:#2563EB;border-radius:12px;color:#fff;text-decoration:none;font-weight:700;">
    Activar acceso
  </a>
</p>
```

## Other Auth/security templates

If Magic Link, Change Email, Reauthentication or Supabase security notification
emails are enabled, apply the same shell and Spanish copy. Do not use the
default English templates in production.

These templates avoid relying on a PKCE verifier stored in the browser that
originated the request and keep authentication messages visually consistent
with application-owned Resend emails.
