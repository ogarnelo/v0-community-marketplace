# MVP Admin Dashboard v1

Ruta nueva:

```txt
/admin/super/mvp
```

Objetivo: que el propietario pueda revisar Wetudy en 5 minutos sin entrar en Supabase.

## Incluye

- KPIs principales: usuarios, anuncios activos, contactos y acuerdos.
- Embudo MVP: usuarios -> anuncios -> contactos -> acuerdos -> confirmaciones.
- Panel de atención: reportes abiertos, acuerdos disputados, visitas y anuncios sin foto.
- Usuarios orgánicos a seguir: perfiles no test/admin que aún no tienen colegio.
- Anuncios con visitas y sin contacto.
- Actividad reciente: registros, anuncios, contactos, acuerdos y reportes.
- Rankings básicos: usuarios por comunidad, demanda por categoría y tipos de usuario.

## No incluye todavía

- Google Analytics.
- Tracking explícito de búsquedas sin resultados.
- Email diario automático.
- Logs técnicos de Vercel dentro del panel.

Esos puntos quedan como fase 2/3 cuando el MVP tenga más tráfico real.
